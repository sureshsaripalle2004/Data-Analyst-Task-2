# Data Analyst Internship - Task 2

## Project Title
Power BI Sales Dashboard

## Objective
To create an interactive dashboard using the Sample Superstore dataset.

## Dashboard Includes
- Total Sales
- Total Profit
- Total Quantity
- Total Orders
- Sales by Category
- Profit by Region
- Monthly Sales Trend
- Sales by Segment
- Profit by Sub-Category

## Tools Used
- Microsoft Power BI Desktop

## Dataset
Sample Superstore Dataset

## Outcome
An interactive dashboard that provides insights into sales performance, profit trends, customer segments, and product categories.
